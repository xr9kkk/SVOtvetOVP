# Помощник общего чата

Локальное расширение для BigBlueButton на `https://bbb04.edu.vsu.ru/`. Читает текст страницы, без OCR и внешних сервисов. Настройки сохраняются в браузере; журнал хранится только на странице.

## Установка

Для повторения любых сообщений включите «Любой повторяющийся текст». Список разрешённых ответов при этом не используется и может быть пустым. Порог разных участников, окно времени, исключение собственных сообщений и пауза продолжают действовать. Отправляется текст последнего совпавшего сообщения, с его регистром и пунктуацией. Это повторение текста участников, а не генерация ответа на вопрос. Режим сохраняется в настройках. После обновления файлов перезагрузите расширение на странице управления расширениями, затем обновите вкладку занятия.

1. Откройте `browser://extensions` в Яндекс Браузере (или `chrome://extensions`).
2. Включите режим разработчика и выберите «Загрузить распакованное расширение».
3. Укажите папку `\...\chat-helper`.
4. Обновите вкладку занятия, откройте общий чат. Справа сверху появится «Помощник чата».
5. Введите своё полное имя ровно как в чате. Проверьте разрешённые ответы и нажмите «Запустить», оставив автоотправку выключенной.
6. Проверьте журнал на новых сообщениях. После проверки остановите помощник, включите автоотправку и снова запустите.

По умолчанию нужны четыре разных имени за 30 секунд. Между срабатываниями — минимум 120 секунд, после каждого срабатывания накопленные голоса сбрасываются. Регистр, конечные точки/восклицательные/вопросительные знаки и варианты тире нормализуются. Ответ должен целиком совпасть с разрешённым: вхождения внутри предложения не учитываются. Имена служат приближением идентификаторов участников; однофамильцы с одинаковыми полными именами считаются одним человеком.

Старые сообщения при запуске исключаются по `data-chat-message-id`. Свои сообщения исключаются по указанному имени. Неизвестные авторы пропускаются. Если в поле уже есть черновик или кнопка недоступна, помощник останавливается. Esc или «Остановить» отключают обработку; после обновления страницы запуск всегда ручной. Если остановить помощник во время подготовки отправки, в поле может остаться подготовленный текст.

Компьютер должен работать, вкладка — оставаться открытой, общий чат — доступным. Спящий компьютер не обрабатывает сообщения; браузер может замедлять фоновые вкладки. Подгруженную позже историю расширение может принять за новые сообщения: во время работы не прокручивайте чат в прошлое. Смена комнаты требует остановки и повторного запуска. Расширение не отвечает на произвольные вопросы и не подтверждает доставку сообщения сервером.

Привязки сделаны по предоставленному HTML. SVG кнопки ищется только возле поля ввода, затем выбирается родительский `button`. Поведение на живой странице необходимо проверить в тестовом режиме; если журнал сообщает об отсутствии автора или кнопки, нужна полная HTML-разметка соответствующего контейнера.
